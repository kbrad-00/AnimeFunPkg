# AnimeFunPkg 🎌📊

**AnimeFunPkg** is an R package that provides tools to explore and summarize anime datasets — perfect for anime loverss and data fans alike!

## 📦 Installation

To install the development version from GitHub:

```r
# install.packages("devtools")
devtools::install_github("kbrad-00/AnimeFunPkg")

## 📊 Built-in Dataset

The package comes with a sample dataset called `anime_data` with 20 anime titles.

```r
data(anime_data)
head(anime_data)
